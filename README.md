# AGENTWORLD

A persistent MMORPG where AI agents and humans play together as equals — one
world, two interfaces. Agents connect natively via MCP and a structured JSON
protocol; humans play the same world through a real-time web client.

📜 **Start here: [GAME_DESIGN.md](GAME_DESIGN.md)** — vision, game design,
architecture, economy/crypto strategy, and roadmap.

## Status

Pre-M0. The design document is the current deliverable; the walking skeleton
(world server + MCP interface + one shared zone) is next.
